## 四、最近一轮做了什么

**这一轮：引用角标 + 原件回溯**（让答案里的 `[1]` 点得下去）

1. **需求是用户"用"出来的** —— 我们已经能说"依据来自国标第 10 页"，
   用户一句"**我想要前端回溯原始的 PDF 不行吗**"才暴露出：说法和入口是两回事。
2. **原件落盘** —— 上传时先留原件（文件名用**内容指纹**，重传同一份天然去重），
   文档表加 `file_name/file_path/preview_path/file_size`。
3. **"转 PDF"不是默认动作，是给 Office 补的例外** —— PDF/图片/txt/csv/md
   **一律原样返回原件**，只有 docx/xlsx/pptx 浏览器渲染不了才转一份预览件。
4. **角标** —— 提示词让模型标 `[1]`，服务端 `CitationSanitizer` 归一化写法
   （全角括号 / 尖括号 / 全角数字），前端**先转义再替换**做成可点角标。
5. **点开跳原件** —— PDF.js 单页渲染，直接停在第 N 页；原件用 fetch 带令牌取字节
   （不暴露可另存/转发的直链）。
6. **五个坑**（记录 43–47 条）：扩展名里的路径穿越、形同虚设的转换超时、
   同一条判据写两处必然漂移、**删文档不删原件**（端到端验证撞出来的）、
   指纹去重只覆盖"重传同一份"。

> **边界照实说**：角标只保证**编号合法**，不保证**标得对**（`[3]` 可能其实是 `[1]` 的内容）——
> 那要靠下一轮的 NLI 逐句校验。也**不做命中句高亮**：那份国标是全扫描件、没有文字层。

**上一轮：证据闸 + 切片结构元数据**

1. **证据闸换判据** —— 标 34 条样本画曲线，发现向量相似度**根本没有可用分界点**（两类完全重叠），**原阈值 0.6 实测漏放率 100%**。换成精排（交叉编码器）后 **100% → 0%**。
   细节：喂精排必须用**「标题+正文」**（标题是问句形态），误拦率 29% → 13%。
2. **召回放宽 + 精排收紧** —— 表格摘要在**向量路排第 2**，却因只走单路被 RRF 累加挤出 top-5，**精排从头到尾没见过它**。改成「召回 20 → 精排 → 取前 5」。
3. **切片结构元数据** —— 按「页 × 章节」拆段、目录剔除、同章节回填、响应带 `sources`。
4. **修了两个"静默失效"bug** —— 会话粘性把完整新问题当追问吃掉；`expandTables` 换构造参数丢元数据。

## 五、核心设计原则（要背）

**① 向量化的是「入口」，不向量化的是「本体」——但本体必须存**
「不向量化」≠「不存」。本体（表格 markdown、父块全文）一律**结构化存库**，靠 `tableId` / `section_path` 取回。

**② 父子块 和 表格，是同一个模式的两次应用**

```
        检索入口（向量化）      本体（不向量化，取回来用）
第一处：  子块                  父块
第二处：  表格摘要              表格本体
```
因为**检索要短而准（长了向量表征就糊），生成要全而完整（缺表头就答错）**。

**③ 融合排序 ≠ 相关性排序** —— RRF 的 `1/(60+名次)` 是累加的，天生偏爱"两路都靠前"，会低估"只在单路极端靠前"的。**融合管"别漏"，精排管"挑准"，不能合成一步。**

**④ 双塔适合排序、不适合判定** —— 向量相似度是"各自算好再比"，对"资料到底有没有回答这个问题"不敏感。

**⑤ 判据选错比阈值调错严重** —— 画曲线的价值是能看出"**选不出来**"。

## 六、踩过的坑（47 条，挑最值得讲的）

| # | 坑 | 教训 |
|---|---|---|
| 11 | 静默降级（8 秒超时 vs 冷启动十几秒） | 静默失败比报错危险 |
| 15 | 跨域被单 Agent 吃掉（`priority` 配了没生效） | 配置写了 ≠ 会生效 |
| 25 | 自评误杀（否定句把注意力引到那东西上） | "防幻觉"本身也会出错 |
| 29 | 证据闸判据选错 | 先证明维度可分，再谈阈值 |
| 36 | embedding 批量上限（16 > 10，潜伏很久） | "一直没出问题" ≠ "没问题" |
| 37 | 串行调外部服务，"慢"和"挂"在用户眼里是一回事 | 独立任务就该并发 |
| 38 | RRF 挤出对的资料 | 融合算法的系统性偏置 |
| 40 | `ClassNotFoundException`（其实是跑 mvn 清了 classes） | 先对时间戳，别急着怀疑代码 |
| **41** | **粘性把"完整新问题"当追问吃掉**（"关键词没命中"≠"是追问"） | **省钱的优化坏掉时会伪装成"能力不足"** |
| **42** | `expandTables` 换构造参数丢字段 → 溯源列表没出处 | **缺省值让"少写了什么"不可见** |
| **43** | **扩展名里带路径，能爬出落盘目录**（`extensionOf` 返回最后一个点之后的全部内容） | **安全校验要问"写路径设防了吗"；白名单 > 黑名单** |
| **44** | 120 秒超时是摆设（`readAllBytes` 先阻塞，走不到 `waitFor`） | **配置声明了 ≠ 生效**（第 15/31 条同类） |
| **45** | 同一条判据写两个地方，必然漂移（`!= null` vs `isBlank()`） | **"规则要写两遍"就是该抽方法的信号** |
| **46** | **删文档不删原件**（端到端验证撞出来的） | **"删除"的完整性要按"数据散在几处"来数**（本例 4 处） |
| **47** | 指纹去重只覆盖"重传同一份"，失败路径照样堆孤儿 | **写"某某保证"的注释时要问它的边界在哪** |

## 八、硬规矩（别踩）

| 规矩 | 为什么 |
|---|---|
| **杀进程只按 PID** | `taskkill /F /IM java.exe` 会连 ES 和 IDEA 一起杀（踩坑第 28 条） |
| **我起的应用用完自己杀** | 否则占着 8082，用户 IDEA 起不来 |
| **别在应用运行时跑 `mvn`** | 会清空重建 `target/classes` → `ClassNotFoundException`（第 40 条） |
| **`.env` 的初始密码改了不生效** | 只在"一个 ADMIN 都没有"时建号；改用 `POST /api/auth/password` |
| **测试数据物理删** | `deleteById` 走逻辑删除清不干净 |
| **改 PATH 后重开终端** | 已开着的 shell 拿不到新值 |
| **导中文 SQL 加 `--default-character-set=utf8mb4`** | 否则按 GBK 读，注释写坏 |
| **跑完测试索引数不应变** | 变了说明清理漏了，会污染检索 |
